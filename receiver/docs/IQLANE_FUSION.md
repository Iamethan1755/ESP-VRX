# IQLaneFusion: analytic research implementation

C5VRX by Twotoz and the C5VRX contributors. This extends the untrained
U85/PAIR formula work in PR #190, the older adaptive lane/gain controller,
and the Gaussian-cell/history study in `legacy/c5vrx4/PHASE8_THREE_BUNDLE.md`.
Source: https://github.com/Twotoz/C5VRX . Official project and Discord invite:
https://twotoz.github.io/C5VRX/ . Existing GPL/source notices remain applicable.

## Implemented, and what is not proved

The host implementation is executable: exact Q10 bit extraction, union-cell
Gaussian likelihood integration, a factorized phase/frequency tracker retaining
multiple hypotheses, mathematical candidate/gain search, sequential route-write
replay, decision persistence, U85Q comparisons and a compressed BS experiment
generator. No fitted weights, camera training or online reward learner.

The firmware's opt-in passive shadow (`J`, `lane_shadow.c`, generated by
`build_lane_shadow.py`) was removed on 2026-10-12 as unused bench code; it
never actuated anything. Retrieve it from git history (PR #196 before
that date) if a new board experiment needs it. Hardware timing, real
displayed video and RF attenuation/range are not validated here.

The reference is NOT a demonstrated replacement for U85Q. The synthetic
fade probe currently regresses substantially despite improvements in some
nominal/weak/fold cases. That negative result is preserved in the JSON report.
The physical-ADC moving PAL test at synthetic C/N6, seed196, 64 phases,
known amplitude/noise and one fixed gain gives U85Q 4.71 dB luma SINAD
versus reference 3.39 dB; both goggle-model sync fractions are 1.0. This
is another regression and a reminder that sync alone is not picture quality.
Do not flash the compressed prototype as an improvement based on the host
reference: the two algorithms have different state and have not been shown
equivalent. This first implementation does not complete safe live adaptation.

## Observation model

`iq_lane_fusion.py` implements flooring and ADC saturation at [-512,511]
followed by the actual selected physical bits. A captured nibble represents
a union of ADC intervals, including the infinite saturated end tails.
For example ultrafine code1 includes [16,32), [144,160), [272,288), [400,416).
ADC pairs (144,16) and (16,144) have equal radius and the same raw byte but
phases 6.34 and 83.66 degrees. A midpoint signed-nibble interpretation cannot
recover that information.

The reference models `z=A*exp(j*phase)+DC+noise`, optional known I/Q ratio and
skew, independent Gaussian axis noise, and explicit radius hypotheses. It
integrates EVERY interval rather than fitting LUT entries. Receiver noise may
actually be correlated or non-Gaussian; model mismatch is not waived by calling
this mathematical. Radius hypotheses are equally weighted in the cell model;
their temporal correlation and phase/frequency correlation are not retained.

The decoder retains a phase probability vector and a separate frequency
probability vector, with explicit Gaussian frequency diffusion (default 2 MHz
per acquired sample), bounded increments +/-12 MHz at IQ40, and contradiction
re-acquisition. These are engineering assumptions, not learned constants or a
proven optimal FM model. Output is the conditional mean within the strongest
contiguous half-height frequency peak; excluded mass is reported as ambiguity.
DMA boundaries do not reset state. A context change or actual gap can reset it.
There is no sync synthesis or video-pixel reconstruction.

## Selection and uncertainty

All four-of-ten bitsets are enumerable: 44,100 I/Q pairs including signless and
asymmetric pairs, or 7,056 with both signs preserved. Gain ratios are optional.
These ratios model a frozen linear chain; LNA/NF/DC changes across real vendor
gain tuples need measured contexts. The selector screens by expected circular
phase uncertainty, then ranks a bounded shortlist by worst-context conditional
frequency MSE in Hz squared. It does not claim a global frequency-MSE optimum.

Frequency risk must condition on a CURRENT observation. Uniform unknown phase
plus one future observation cannot identify an increment. `expected_pair_risk`
averages conditional risks over the existing ultrafine current observation.
With an actual phase posterior, pass it explicitly. Modulo phase loss is only
a screening tool; it cannot hide full-turn frequency errors in the final score.

Shadow tables integrate eight explicit contexts: radii32/64/128/256 ADC LSB,
noise sigma8/24 per axis, 64 phases and six plans (three standard, two mixed,
one asymmetric). They are NOT a measurement of the unseen ADC bits, nor an
offline-trained lane ranking. The shadow requires at least 10% modeled benefit
in ALL eight contexts, three agreeing observations and two seconds of
persistence. Disagreement returns HOLD_OR_UNCERTAIN. No evidence/context change
invalidates readiness. Every proposal is MODEL_ONLY, never permission to act.
This grid is finite and can omit the real channel; confidence is model-limited.

## Commands

From the repository root, using Python with numpy/scipy/numba:

```sh
OPENBLAS_NUM_THREADS=1 python test/test_iq_lane_fusion.py
OPENBLAS_NUM_THREADS=1 python research/lane_fusion_study.py search --all-bits --phases 32
OPENBLAS_NUM_THREADS=1 python research/lane_fusion_study.py probe
OPENBLAS_NUM_THREADS=1 python research/lane_fusion_study.py video
OPENBLAS_NUM_THREADS=1 python research/lane_fusion_study.py export --plan mixed468 --output /tmp/mixed.bsasm
```

`probe` reports six deterministic synthetic FM cases: amplitude, folding,
weak noise, a deep fade and an echo. Calibration is fixed from each clean
counterpart before evaluating its noisy input. These are not PAL/NTSC
acceptance scores. `video` exercises a full moving synthetic PAL field with
the goggle model, using known synthetic amplitude/noise context. It can take
minutes. `data/iq_lane_fusion_*.json` preserves results and evidence labels.

`sim.make_case(physical_adc=True)` now provides actual folding and ONE gain
shared by clean/noisy inputs, plus analog ADC input for oracle research.
Default legacy clamp/instantaneous-normalization behavior is preserved for old
studies. Old reports therefore remain old-model results, not folding proofs.

## Compressed experiment and switching gate

`iq_lane_mixed468.bsasm` is an assembled, fixed-context candidate, not selected
by firmware. It keeps U85Q's shared LUT16 transition plane, 32 phase states,
32 tokens, two bundles per 50 ns, 20 MS/s unique DAC duplicated at TX40.
The analytic decoder plane replaces the usual signed-nibble midpoint with a
physical-cell phase mode. Low concentration uses U85Q's quadrant tokens.
It fits a 2-KiB LUT. Sign-on-bit3 and centred isotropic contexts are required
for this exporter; the full reference supports broader observations.

Route the specified bits BEFORE starting this program. The compressed tracker
does not retain the full reference posterior. Export/assembly/resource fit is
not sustained throughput, DAC correctness, displayed-picture or range proof.

Safe live arbitrary-bit switching remains unresolved. GPIO matrix writes are
sequential; line permutations may even briefly duplicate a source bit. More
importantly, old and new encodings coexist in the raw ring and the prefetched
BS input. A global lane variable cannot tell the sample decoder their epochs.
The current IDF `bitscrambler_load_lut` implementation changes LUT width and
writes words sequentially. It is not an atomic live table swap.

Required next proof: coherent sample-level encoding/decoder handover, including
prefetch and every ring alignment, plus hardware timing. Candidate routes are
a single resident compatible decoder, sample-carried mode metadata (costing IQ
bits), or a demonstrated hardware-bank handover. None is assumed available.
Observer settling alone does not protect the demodulator from mixed samples.

## Unused hardware audit

The current U85Q program does not use BitScrambler counters A/B or their
comparison/conditional machinery. Each counter is 16-bit; arithmetic/load
and high/low-byte operations can potentially retain phase/frequency history
outside the current five phase-state bits. This is the strongest next hardware
candidate. Counters do not expand the LUT address space; extra operations and
source-routing conflicts must still fit the two-bundle throughput budget.
Earlier Phase8/history/counter experiments are donor research, not a novel
discovery, and their three-bundle/75-ns tradeoffs are not carried over silently.

ETM can trigger peripheral tasks, including simultaneous GPIO SET/CLEAR/TOGGLE.
Those actions do not change eight GPIO matrix source registers atomically.
Timing assistance is plausible; coherent route/decoder switching is unproved.

The LP-core exists and supports ETM, but has a separate memory/access budget.
A bounded mailbox-fed diagnostic/control calculation is a candidate; it is not
an established second 40-MS/s IQ demodulator or live RF-SRAM reader. Offloading
the very small current shadow is unnecessary until measured HP load warrants it.

PCNT can provide peripheral-level pulse/edge diagnostics without software on
every edge. That does not supply missing multibit ADC observations. Auxiliary
SPI/RMT capture likewise has no demonstrated continuous synchronized wider IQ
path here. RX+TX BS coexistence and active RF-SRAM visibility already failed
under the historical tested architectures: see `legacy/c5vrx3/docs/pr-derived-findings.md`
and `legacy/c5vrx3/docs/continuous-iq-findings.md` before repeating them.
